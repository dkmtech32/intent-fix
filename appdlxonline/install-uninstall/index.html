📱 วิธีติดตั้ง / ถอนการติดตั้ง (Installation / Uninstallation Instructions)

🔧 วิธีติดตั้ง:

  1. คลิกที่ลิงก์ ดาวน์โหลด เกมหรือบริการที่คุณต้องการ
  2. รอให้เบราว์เซอร์ดาวน์โหลดไฟล์จนเสร็จ ระบบจะถามว่าคุณต้องการติดตั้งหรือไม่
  3. กดปุ่ม ตกลง (OK) หรือ ติดตั้ง (Install) เพื่อเริ่มกระบวนการ
  4. ระบบอาจขออนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก ให้เปิดอนุญาตชั่วคราวแล้วติดตั้ง
  5. เมื่อเสร็จสิ้น ให้เปิดแอปเพื่อตั้งค่าเริ่มต้น
  6. หากมีข้อความยืนยัน เช่น SMS ยืนยัน ให้กรอกตามที่ระบุ
  7. จากนั้นสามารถกลับสู่หน้าเกมหรือแอปเพื่อเริ่มเล่นและใช้งานได้ทันที

🌸 ขอให้สนุกกับการเล่นเกมและใช้งานบริการของเรา!

❌ วิธีถอนการติดตั้ง:

หากต้องการลบเกมหรือแอปออกจากโทรศัพท์มือถือ Android สามารถทำตามขั้นตอนดังนี้:

อุปกรณ์ Android:

หน้าหลัก (Home) → การตั้งค่า (Settings) → แอปพลิเคชัน (Apps)
เลือกแอปที่ต้องการ → กด ถอนการติดตั้ง (Uninstall)
ยืนยันการลบด้วย ยอมรับ (Yes / OK) ระบบจะลบแอปให้เสร็จสมบูรณ์
