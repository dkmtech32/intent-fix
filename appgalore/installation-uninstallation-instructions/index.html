Cara Memasang dan Nyahpasang

📥 Memasang Aplikasi APK daripada AppGalore

  1. Buka laman web AppGalore melalui pelayar pada peranti Android anda.
  2. Pilih aplikasi yang anda inginkan dan tekan butang Muat Turun.
  3. Apabila fail APK selesai dimuat turun, ketik untuk membukanya.
  4. Jika terdapat mesej amaran, aktifkan "Benarkan pemasangan daripada sumber tidak diketahui".
  5. Sahkan pemasangan dan tunggu sehingga proses selesai.

🗑️ Nyahpasang Aplikasi

  1. Pergi ke menu Tetapan (Settings) pada telefon anda.
  2. Pilih Aplikasi atau Pengurusan Aplikasi.
  3. Cari aplikasi yang ingin dipadamkan.
  4. Ketik nama aplikasi dan tekan Nyahpasang.
  5. Sahkan penghapusan apabila diminta oleh sistem.

💡 Petua Tambahan

  • ✅ Muat turun hanya dari laman web yang dipercayai seperti AppGalore.
  • ✅ Semak versi Android anda sebelum pemasangan.
  • ✅ Jika aplikasi gagal dipasang, cuba mulakan semula peranti dan pasang semula.

Terima kasih kerana menggunakan AppGalore
